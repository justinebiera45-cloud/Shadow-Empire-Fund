SHADOW EMPIRE DASHBOARD PREVIEW
================================

Files:
- dashboard.html: contributor dashboard visual preview
- admin-preview.html: admin dashboard visual preview

These are static interface previews only. They do not implement accounts,
authentication, payment collection, payment verification, or a database.
Do not collect passwords, bank details, GCash credentials, or personal data
through these pages.

INSTALLATION:
1. Open your GitHub repository: justinebiera45-cloud/Shadow-Empire-Fund
2. Upload dashboard.html and admin-preview.html to the same folder as index.html.
3. In index.html, add this link inside the existing navigation:
   <a href="dashboard.html">DASHBOARD</a>
4. Optionally add a dashboard section linking to dashboard.html and
   admin-preview.html.
5. Commit the changes. GitHub Pages will publish the files.

The admin preview is not access-controlled. Do not treat a hidden URL as
security. A real admin area requires secure authentication and server-side
authorization, and should be set up with a trusted adult project owner.
